# **App Name**: Maricá Prep Focus

## Core Features:

- User and Admin Authentication: Secure login system for students and administrators, including distinct role-based access control to specific application areas and functionalities.
- Question Bank Management: Comprehensive CRUD operations (Create, Read, Update, Delete) for administrators to manage exam questions, subjects, and topics.
- Student Question Practice System: An interactive, exam-style interface for students to answer multiple-choice questions, featuring automatic correction and detailed explanations for each answer.
- Intelligent Review and Performance Tool: An AI-powered tool that automatically identifies and schedules review sessions for students based on their historical errors and performance patterns.
- Student Progress Dashboard: A personalized dashboard for students to monitor their overall study progress, visualize strengths, weaknesses, and track performance metrics per subject and topic.
- Gamification System: Incorporation of gamified elements such as XP points, user levels, and study streaks to encourage consistent engagement and motivation among students.
- Bulk Question Import: Admin functionality to upload and parse questions in bulk via a structured JSON file, facilitating rapid content population.

## Style Guidelines:

- Primary Color: A stable and engaging medium blue (#2662D9) to signify trust and focus, aligning with educational professionalism.
- Background Color: A very light, almost off-white, cool-toned gray (#F0F2F4) to ensure maximum readability and a clean interface for long study sessions.
- Accent Color: A vibrant cyan-blue (#47D0EB) to highlight interactive elements, calls to action, and important notifications, providing visual pop and contrast.
- Primary Font: 'Inter' (sans-serif) for both headlines and body text. Chosen for its exceptional legibility, clean lines, and modern aesthetic, consistent with Material Design principles.
- Utilize a consistent set of Google Material Design icons, opting for clear, vector-based glyphs that enhance clarity and intuitive navigation across the application.
- Implement a 'mobile-first' responsive design with a clean, card-based layout structure that adapts seamlessly across desktop and mobile screens, focusing on clear information hierarchy.
- Apply subtle, non-intrusive animations and transitions (e.g., fades, slides) to provide smooth user feedback, improve perceived performance, and enhance the overall interactive experience without distraction.
